## 1. 排版层

读者判定"这是 AI 写的"通常不超过三秒，靠的就是这一层。

| 痕迹 | 样子 | 改法 |
|---|---|---|
| emoji 小标题 | `## 🚀 核心优势` `### 💡 关键洞察` | 全部删掉，标题只留文字 |
| 加粗轰炸 | 每个列表项开头都是 `**关键词**：解释` | 加粗只留真正的结论，一屏 ≤2 处 |
| 机械列表 | 正常叙述被拆成 5 条平行短句，每条一行 | 能连成段的连成段，列表只留真并列项 |
| 分隔线滥用 | 每两段一条 `---` | 只在真正换大节时用 |
| 三级标题过密 | 300 字里三个小标题 | 短文不分节；长文按内容分，不按对称分 |
| 弯引号 / 半角标点混用 | `"这样"` 与 `"这样"` 混排、中文句子里出现 `,` `.` | 中文全角统一，按目标平台规范 |
| 表格癖 | 两三个要点也做成表格 | 少于三行三列的表格改成句子 |
| 每段等长 | 段段 3–4 行，节奏平坦 | 故意留一两个一句话的短段 |

## 2. 词汇层

### 2.1 高频"AI 词"

出现一两个不算问题，密集出现就是信号：

赋能、抓手、闭环、维度、格局、生态、链路、心智、颗粒度、深耕、沉淀、复盘、对齐、拉齐、打法、势能、跃迁、范式、底座、护城河、全链路、端到端、一站式、无缝、丝滑、极致、强大而直观、至关重要、核心关键、深入探讨、深度解析、全面剖析、彰显、凸显、诠释、见证、织就、绘就、擘画、赋予、注入新动能、日益、愈发、崭新、蓬勃、蔚然成风

### 2.2 翻译腔

英文模板直译过来的表达，中文里读着别扭：

| 翻译腔 | 来源 | 改法 |
|---|---|---|
| 作为……的证明 | a testament to | 直接说事实 |
| 在不断演变的……格局中 | in the evolving landscape | 删掉 |
| 值得注意的是 | it's worth noting | 删掉，重要就直接说 |
| 让我们深入探讨 | let's dive into | 删掉 |
| 这不仅仅是……更是…… | it's not just… it's… | 删掉或改成一句陈述 |
| 无缝的、直观的、强大的 | seamless, intuitive, powerful | 换成具体能力 |
| 在当今快速发展的时代 | in today's fast-paced world | 删掉 |
| 释放……的潜力 | unlock the potential | 说清楚具体能做什么 |
| 拥抱变化 / 引领未来 | embrace / lead the future | 删掉 |

句法层面的翻译腔：长定语链（"一个基于云原生架构的、面向企业级用户的解决方案"）拆成短句；被动堆叠（"被优化""被赋予"）改主动；"基于……""通过……来……""对于……而言""在……方面""从……的角度来看"多数可以直接删掉。

### 2.3 空心动词短语

"进行了深入的探索""实现了效率的提升""完成了体系的构建""带来了体验的升级"——名词化把动作抽空了。

改法：还原成动词 + 具体宾语。"实现了效率的提升"→"构建时间从 20 分钟降到 6 分钟"。

### 2.4 过度限定

"可能""通常""在某种程度上""一般而言""某种意义上说"堆在一起，句子就失重了。一句里最多一个限定词，其余删掉；确实不确定就说清楚不确定在哪。

### 2.5 绝对化词

所有人、每个人、永远、从不、无一例外——用绝对词干模糊的活。改成有边界的表述，或者给反例留出空间。

### 2.6 工程师腔 / 调试腔

AI 模仿 SRE 复盘文风的标志词，出现在非技术场景就是强信号：

稳稳兜住、稳稳接住、收口、收窄、收敛、砍一刀、打掉、落盘、兜底、压实、锁住、对上了、坐实了、拆开看、口径、抠出来、揪出来、我不猜、补一刀、更狠一点、根因（技术复盘之外）

**误判防护**：真正的故障报告、changelog、带具体参数的调试对话里，"根因""收敛""兜底"是正常术语，不要动。判断标准：主语是不是真实系统、有没有具体数据。

### 2.7 自媒体腔

批量生产的"网感"。真人偶尔用，AI 每篇都用：

保姆级、硬核、干货、拆解、盘点、避坑、一文读懂、万字长文、建议收藏、划重点、绝绝子、谁懂啊、真的会谢、狠狠（XX 了）

带着具体经历的"踩坑"是真实表达；孤零零的标题词堆砌才是信号。

### 2.8 抒情词修饰抽象概念

安放、抵达、微光、褶皱、丰盈、滚烫、轻盈、剥开、锋利、柔软——落在"记忆、成长、时代、情绪"这类抽象名词上，且一段出现两个以上，就是公众号 AI 腔。落在具体物体上（"把药盒安放在床头"）是正常表达；文学创作不适用此条。

### 2.9 分析腔 / 点评腔

AI 爱给自己的表达贴风格标签、给内容做二次包装。这些词一出现基本可以直接删：

- **表达自评**：直白（"说得直白点"）、朴素（"原因很朴素"）、实在（"最实在的做法"）、坦白、赤裸——删掉包装，直接说内容。"说得直白点，就是 X"→"X"。
- **分析动词**：洞察、拆解、梳理、剖析、解构、聚焦——换成"看出 / 讲 / 列出来"这类普通动词，或者删掉动词直接给结果。
- **伪学术名词**：叙事（"宏大叙事"式滥用）、核心价值、底层逻辑、方法论——说清楚具体是什么：核心价值→到底好在哪，底层逻辑→原因。

**误判防护**：真人形容别人"他说话很直白"是正常表达；BI 产品里"洞察"是功能名。信号是 AI 拿这些词**点评自己正在说的话**或给结论贴标签。

## 3. 句式层

**三元并列**：`高效、智能、便捷` `更快、更稳、更省` —— AI 最稳定的指纹。留最准的一个，或换成一句具体的话。全文允许出现一次。

**否定式排比**：`不是 X，而是 Y` / `不仅 X，更是 Y` / `与其说是 X，不如说是 Y`，以及变体 `表面上/看似 X，却/背后是 Y` `问题不在于 A，而在于 B` `你以为 A，其实 B` —— 全文最多一次，且要真有对比价值。只把语序倒过来（"Y，不是 X"）不算改。

**系动词回避**：`作为……的存在` `扮演着……的角色` `充当` `标志着` `成为了……的代名词` —— 绕开"是"的说法。直接用"是""有""就是"。

**同义词循环**：同一个东西两三句内连续换名（解析器→该组件→这一模块），越换越抽象。统一回最具体的那个词——术语重复是精确，换词回避才是 AI 味。改写时自己也不要靠换同义词来降低某个词的出现频率。

**预设反驳**：`我不是说……` `需要澄清的是，这并不意味着……` —— 回应一个没人提出的反对意见。删掉，或把里面真正的主张直接说出来。有人真提过的反驳、正面回答完的反驳保留。

**拒绝假选项**：`你可能会想……但` `一个看似可行的办法是……然而` —— 引入一个没人会选的选项再否定它，是草稿残留。设计文档、教程里读者真会考虑的备选方案保留。

**对仗金句癖**：每段结尾都给一句工整的短句总结。删掉大部分，留一句都算多。

**设问开场**：`什么是 X？简单来说，……` —— 直接从事实开始。

**破折号插入语**：中文里 `——` 密集出现是明显信号。改成句号断开，或者去掉插入部分。

**排比铺陈**：`从 A 到 B，从 C 到 D` 连用。留一组。

**连接词报幕**：`首先……其次……最后` `此外` `因此` `综上所述`。段落顺序应该靠内容成立，删掉这些词后如果读不通，说明段落顺序本身有问题。

**句长趋同**：连续三句字数接近就改一句。真人写作长短起伏很大。

## 4. 结构层

- **总分总模板**：开头定义 + 中间三点 + 结尾升华。打破它：直接从最有信息量的地方开始。
- **强行对称**：每节都是三小点、每点都是两句话。真实内容不会这么整齐，重要的部分就该写得更长。
- **同构小节**：相邻小节共用同一套内部结构（都是"观点—例子—收束句"）。相邻小节换不同的展开方式；全文最多一个编号列表段。
- **"挑战与展望"结尾**：凑数段落，删。
- **开头铺垫**：`随着人工智能的快速发展，越来越多的企业开始……` —— 删掉，第一句就给结论或场景。
- **结尾升华**：`未来已来""让我们一起拥抱变化""希望这篇文章对你有帮助`。收在最后一个具体事实上，或收在一个真实的未解问题上。

## 5. 内容层

- **拔高意义**：把一次普通更新说成"里程碑""革命""重新定义"。降回原尺寸。
- **模糊归因**：`业内人士普遍认为""研究表明""有数据显示` 而无出处。要么补出处，要么删掉，要么改成"我的判断是"。如果数字或预测完全依赖那个缺失的出处（"研究表明效率提升 40%"），删掉整个论断，**不要降级成模糊说法**（"效率明显提升"）——那只是把假变得更难查。正式文档里不代改，标注"缺出处"即可。
- **装饰性假细节**：`凌晨三点` `第三杯咖啡已经凉了` `窗外下着雨` —— 没有来源、删掉也不影响事实和因果的氛围细节。这是"注入人味"最常见的翻车方式：假细节比套话更像 AI。用户真实提供的细节、承担因果的细节保留。
- **借喻场混用**：赛道、战场、地基、风口、浪潮、护城河……一段里混用三个以上不同来源的比喻系统。全部还原成字面意思，一个都别放回去。行业里已经字面化的词（金融的"杠杆"）不算。
- **正确的废话**：`平衡好效率与质量至关重要`。删。
- **缺具体**：全篇没有一个数字、时间、人名、产品名、失败案例。这是 AI 味最深的一层，前面全改对了也救不回来。补具体的信息必须来自原文或用户，缺就列出来问。
- **只有好消息**：真实经验里一定有代价、有妥协、有走过的弯路。写出来。

## 6. 对话痕迹

从聊天里粘出来的稿子常带这些，交付前必须清干净：

- `这是一个很好的问题` / `当然可以` / `希望对你有帮助` / `如果你需要，我可以进一步……`
- 主动出击腔：`要不要我帮你……` / `只要你回复我，我立马开始` / `你就确认一点`
- 表演式坦诚：`我必须诚实地说` / `说句实话` / `坦白讲`（后面跟的往往是普通信息）——删掉预告，直接说
- `作为一个 AI 模型` / 知识截止日期声明
- `以下是……` 开头的交付语
- 章节末尾的 `总结：` 小节（正文已经说完了）
- 谄媚语气：`您提到的这一点非常关键`

## 7. 高频词替换表

不是禁用，是提醒：出现时问一句"这里到底想说什么"。

| 少用 | 换成 |
|---|---|
| 赋能 | 让……能够 / 帮……做到（说清楚是谁帮谁） |
| 抓手 | 办法 / 切入点 |
| 闭环 | 说清楚从哪到哪 |
| 深耕 | 做了几年 / 具体做了什么 |
| 至关重要 | 说清楚不做会怎样 |
| 无缝 | 具体到不用手动做哪一步 |
| 极致 | 给数字 |
| 深入探讨 | 直接讲 |
| 打造 | 做 / 建 / 写 |
| 助力 | 帮 |
| 显著提升 | 从 X 到 Y |
| 一系列 | 给出个数或直接列 |
| 洞察 | 说清楚看到了什么 |
| 拆解 / 梳理 | 讲 / 列出来 |
| 核心价值 | 说清楚到底好在哪 |

## 8. 误判防护

有些表达看着像 AI，其实是原作者的正常表达或者领域规范。改之前先分辨：

- **技术文档、合同、公告、论文摘要**里的书面语和被动句是规范，不是 AI 味。只清理套话和翻译腔。
- **引用的原文、他人发言、法条、数据**一律不动。
- **术语的准确重复**不是"刻意换词"的反面案例——同一概念在同一篇里就该用同一个词，不要为了"变化"制造同义词循环。
- **作者本人的口头禅**如果在样本里反复出现，那是声音，保留。
- 用户明确要求的正式语气优先。
- **单个痕迹不定罪**。一处破折号、一个"然而"、一个"此外"说明不了什么；判定靠的是多类痕迹在同一段里聚集。宁可漏报，不要把干净的稿子改花。
