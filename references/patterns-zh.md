## 1. 排版层

读者判定"这是 AI 写的"通常不超过三秒，靠的就是这一层。

| 痕迹 | 样子 | 改法 |
|---|---|---|
| emoji 小标题 | `## 🚀 核心优势` `### 💡 关键洞察` | 全部删掉，标题只留文字 |
| 加粗轰炸 | 每个列表项开头都是 `**关键词**：解释` | 加粗只留真正的结论，一屏 ≤2 处 |
| 机械列表 | 正常叙述被拆成 5 条平行短句，每条一行 | 能连成段的连成段，列表只留真并列项 |
| 分隔线滥用 | 每两段一条 `---` | 只在真正换大节时用 |
| 三级标题过密 | 300 字里三个小标题 | 短文不分节；长文按内容分，不按对称分 |
| 弯引号 / 半角标点混用 | `"这样"` 与 `"这样"` 混排、中文句子里出现 `,` `.` | 中文全角统一，按目标平台规范 |
| 表格癖 | 两三个要点也做成表格 | 少于三行三列的表格改成句子 |
| 每段等长 | 段段 3–4 行，节奏平坦 | 故意留一两个一句话的短段 |

## 2. 词汇层

### 2.1 高频"AI 词"

出现一两个不算问题，密集出现就是信号：

赋能、抓手、闭环、维度、格局、生态、链路、心智、颗粒度、深耕、沉淀、复盘、对齐、拉齐、打法、势能、跃迁、范式、底座、护城河、全链路、端到端、一站式、无缝、丝滑、极致、强大而直观、至关重要、核心关键、深入探讨、深度解析、全面剖析、彰显、凸显、诠释、见证、织就、绘就、擘画、赋予、注入新动能、日益、愈发、崭新、蓬勃、蔚然成风

### 2.2 翻译腔

英文模板直译过来的表达，中文里读着别扭：

| 翻译腔 | 来源 | 改法 |
|---|---|---|
| 作为……的证明 | a testament to | 直接说事实 |
| 在不断演变的……格局中 | in the evolving landscape | 删掉 |
| 值得注意的是 | it's worth noting | 删掉，重要就直接说 |
| 让我们深入探讨 | let's dive into | 删掉 |
| 这不仅仅是……更是…… | it's not just… it's… | 删掉或改成一句陈述 |
| 无缝的、直观的、强大的 | seamless, intuitive, powerful | 换成具体能力 |
| 在当今快速发展的时代 | in today's fast-paced world | 删掉 |
| 释放……的潜力 | unlock the potential | 说清楚具体能做什么 |
| 拥抱变化 / 引领未来 | embrace / lead the future | 删掉 |

### 2.3 空心动词短语

"进行了深入的探索""实现了效率的提升""完成了体系的构建""带来了体验的升级"——名词化把动作抽空了。

改法：还原成动词 + 具体宾语。"实现了效率的提升"→"构建时间从 20 分钟降到 6 分钟"。

### 2.4 过度限定

"可能""通常""在某种程度上""一般而言""某种意义上说"堆在一起，句子就失重了。一句里最多一个限定词，其余删掉；确实不确定就说清楚不确定在哪。

## 3. 句式层

**三元并列**：`高效、智能、便捷` `更快、更稳、更省` —— AI 最稳定的指纹。留最准的一个，或换成一句具体的话。全文允许出现一次。

**否定式排比**：`不是 X，而是 Y` / `不仅 X，更是 Y` / `与其说是 X，不如说是 Y` —— 全文最多一次，且要真有对比价值。

**对仗金句癖**：每段结尾都给一句工整的短句总结。删掉大部分，留一句都算多。

**设问开场**：`什么是 X？简单来说，……` —— 直接从事实开始。

**破折号插入语**：中文里 `——` 密集出现是明显信号。改成句号断开，或者去掉插入部分。

**排比铺陈**：`从 A 到 B，从 C 到 D` 连用。留一组。

**连接词报幕**：`首先……其次……最后` `此外` `因此` `综上所述`。段落顺序应该靠内容成立，删掉这些词后如果读不通，说明段落顺序本身有问题。

**句长趋同**：连续三句字数接近就改一句。真人写作长短起伏很大。

## 4. 结构层

- **总分总模板**：开头定义 + 中间三点 + 结尾升华。打破它：直接从最有信息量的地方开始。
- **强行对称**：每节都是三小点、每点都是两句话。真实内容不会这么整齐，重要的部分就该写得更长。
- **"挑战与展望"结尾**：凑数段落，删。
- **开头铺垫**：`随着人工智能的快速发展，越来越多的企业开始……` —— 删掉，第一句就给结论或场景。
- **结尾升华**：`未来已来""让我们一起拥抱变化""希望这篇文章对你有帮助`。收在最后一个具体事实上，或收在一个真实的未解问题上。

## 5. 内容层

- **拔高意义**：把一次普通更新说成"里程碑""革命""重新定义"。降回原尺寸。
- **模糊归因**：`业内人士普遍认为""研究表明""有数据显示` 而无出处。要么补出处，要么删掉，要么改成"我的判断是"。
- **正确的废话**：`平衡好效率与质量至关重要`。删。
- **缺具体**：全篇没有一个数字、时间、人名、产品名、失败案例。这是 AI 味最深的一层，前面全改对了也救不回来。补具体的信息必须来自原文或用户，缺就列出来问。
- **只有好消息**：真实经验里一定有代价、有妥协、有走过的弯路。写出来。

## 6. 对话痕迹

从聊天里粘出来的稿子常带这些，交付前必须清干净：

- `这是一个很好的问题` / `当然可以` / `希望对你有帮助` / `如果你需要，我可以进一步……`
- `作为一个 AI 模型` / 知识截止日期声明
- `以下是……` 开头的交付语
- 章节末尾的 `总结：` 小节（正文已经说完了）
- 谄媚语气：`您提到的这一点非常关键`

## 7. 高频词替换表

不是禁用，是提醒：出现时问一句"这里到底想说什么"。

| 少用 | 换成 |
|---|---|
| 赋能 | 让……能够 / 帮……做到（说清楚是谁帮谁） |
| 抓手 | 办法 / 切入点 |
| 闭环 | 说清楚从哪到哪 |
| 深耕 | 做了几年 / 具体做了什么 |
| 至关重要 | 说清楚不做会怎样 |
| 无缝 | 具体到不用手动做哪一步 |
| 极致 | 给数字 |
| 深入探讨 | 直接讲 |
| 打造 | 做 / 建 / 写 |
| 助力 | 帮 |
| 显著提升 | 从 X 到 Y |
| 一系列 | 给出个数或直接列 |

## 8. 误判防护

有些表达看着像 AI，其实是原作者的正常表达或者领域规范。改之前先分辨：

- **技术文档、合同、公告、论文摘要**里的书面语和被动句是规范，不是 AI 味。只清理套话和翻译腔。
- **引用的原文、他人发言、法条、数据**一律不动。
- **术语的准确重复**不是"刻意换词"的反面案例——同一概念在同一篇里就该用同一个词，不要为了"变化"制造同义词循环。
- **作者本人的口头禅**如果在样本里反复出现，那是声音，保留。
- 用户明确要求的正式语气优先。
